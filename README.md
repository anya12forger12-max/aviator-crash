# GP Aviator debug APK

Permanent public download for the debug Android build.

- APK: `gp-aviator-debug.apk` (SHA-256 in `SHA256SUMS.txt`)
- Direct URL: https://raw.githubusercontent.com/anya12forger12-max/aviator-crash/apk-release/gp-aviator-debug.apk
- Current gateway URL: `gateway-url.txt` in this branch

The gateway is a temporary Cloudflare Quick Tunnel and can change when the
local tunnel restarts. The APK has the URL above baked in, but the app's
in-app gateway setting can override it without reinstalling.

This branch exists only to publish the APK over a stable, public HTTPS URL.
